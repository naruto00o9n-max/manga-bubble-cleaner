# أرسل صورة إلى Discord واستلمها بعد التبييض

الأمر الجديد `/clean image` يحتاج الصورة فقط. يكتشف النص ويصنع القناع تلقائيًا، ويبيض النص داخل الفقاعات البيضاء محليًا، ويرسل المناطق ذات الخلفيات الملونة إلى خدمة IOPaint/LaMa المستضافة. يرجع PNG بأبعاد الصورة نفسها، مع حفظ كل بكسل خارج القناع.

**حالة الجودة: نموذج تجريبي يعمل، وليس ضمانًا لترميم كل خلفية صعبة بدقة الأصل.** نجح اختبار آلي على فقاعة إنجليزية فعلية، وعلى نص أُضيف للاختبار فوق أوراق وفروع ملونة. في الاختبار الثاني اختفى النص مع تغير بعض تفاصيل الخلفية. لم يكتشف الكاشف المؤثرات الكورية المزخرفة في عينات أخرى؛ لا يصح القول إنه يزيل كل النصوص أو كل مؤثرات SFX تلقائيًا.

## التشغيل

استخدم Python 3.11+ وتطبيق Discord تجريبيًا مستقلًا. لا تستخدم توكن بوتك الحالي إذا أردت إبقاء أوامره كما هي.

```bash
python3 -m venv .venv-manga-cloud
.venv-manga-cloud/bin/pip install -r tools/retouch-lab/requirements-auto.txt
export DISCORD_BOT_TOKEN=YOUR_NEW_DISCORD_BOT_TOKEN
export DISCORD_GUILD_ID=YOUR_TEST_SERVER_ID
export DISCORD_ALLOWED_USERS=YOUR_DISCORD_USER_ID
.venv-manga-cloud/bin/python tools/retouch-lab/auto_bot.py
```

أضف تطبيق Discord بنطاقي `bot` و`applications.commands` وصلاحيتي إرسال الرسائل وإرفاق الملفات، ثم استخدم `/clean` وأرفق الصورة. لا يحتاج Message Content Intent. النتائج خاصة بصاحب الطلب. لم يُختبر اتصال Discord حيًا في هذه البيئة لعدم توفر توكن جديد.

لا يحتاج هذا المسار ملف Retouch أو حسابه أو نقاطه أو بريدًا مؤقتًا. أول طلب ينزل كاشف النصوص مرة واحدة، بحجم يقارب 90 MB، ويتحقق من SHA-256. هذا كاشف يعمل على CPU؛ نموذج ترميم الخلفيات يعمل عند صاحب الخدمة، ولا ينزل إلى جهازك. تشغيل البوت نفسه يحتاج جهازًا أو استضافة CPU، ولا يحتاج GPU.

يمكن تعيين `COMIC_TEXT_DETECTOR_PATH` إلى وزن الكاشف الموجود عندك. المصدر هو إصدار `beta-0.2.1` من [manga-image-translator](https://github.com/zyddnys/manga-image-translator)، والبصمة مثبتة في `auto_mask.py`. راجع أيضًا إشعارات النموذج في [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

## اختبار صورة دون Discord

```bash
.venv-manga-cloud/bin/python tools/retouch-lab/free_cloud.py \
  /path/input.png /path/cleaned.png --mask-output /path/detected-mask.png
```

لا تُدخل قناعًا؛ الملف الأخير اختياري لمراجعة ما اكتشفه الكاشف. الصور المقبولة PNG وJPEG وWebP حتى 20 MB و25 مليون بكسل. يعالج الصفحات الطويلة على مناطق مع سياق محيط، ويقبل طلبًا واحدًا في كل مرة. إذا احتاجت الصورة أكثر من 8 طلبات سحابية أو تجاوزت المهلة، يطلب لوحات أصغر. إذا رفضت الخدمة الطلب أو فشل فحص النص الناتج، يعرض خطأ ولا يدعي نجاح صورة ناقصة.

## المجانية وحدود الخدمة

الخدمة المستخدمة هي [واجهة IOPaint/LaMa العامة لصاحب المشروع](https://huggingface.co/spaces/Sanster/iopaint-lama)، وعنوان واجهة المعالجة `https://sanster-iopaint-lama.hf.space/api/v1/inpaint`. نجحت الطلبات التجريبية دون حساب أو توكن أو نقاط. لم نغيّر نموذج الخدمة أو إعداداتها العامة؛ استُخدم طلب معالجة صورة فقط.

هذه واجهة عامة تجريبية يملكها طرف آخر؛ ليست استضافة مضمونة للبوت، وقد تتوقف أو تنام أو تحد الطلبات. لا تعني استجابة ناجحة أنها ستظل مجانية أو متاحة بلا حدود. لا يتضمن البرنامج تدوير حسابات أو تجاوز حصص أو تحايلاً على اشتراكات. الصور المحددة تُرسل إلى هذه الخدمة، وليست معالجتها محلية بالكامل.

جُرّب أيضًا FLUX Fill المستضاف مجانًا: أعاد تفاصيل في اختبار، وولّد حروفًا بديلة أو ضجيجًا في اختبارات أخرى، ثم توقفت الطلبات بسبب حصة ZeroGPU. لذلك لم يُعتمد كخدمة البوت الافتراضية. محاولة Qwen Image Edit رُفضت بالحصّة ولم تُنتج صورة؛ لا يوجد حكم على جودته من هذه المحاولة.

لا توجد وسيلة لإثبات التطابق مع رسم محجوب أصلًا إلا إذا توفرت نسخته قبل إضافة النص. هدف النموذج ترميم مقنع؛ قد يخترع أو يطمس تفاصيل داخل التحديد. حفظ البكسلات خارج القناع مضمون في الكود، أما جودة الرسم داخل القناع وكمال كشف النص فلهما الحدود الموضحة أعلاه.

## التحقق

```bash
cd tools/retouch-lab
../../.venv-manga-cloud/bin/python -m unittest -v test_autoclean
```

الاختبارات تشمل حفظ المناطق غير المحددة، وتبييض الفقاعات السادة دون شبكة، وعدم قبول رفض الخدمة أو الحروف المكتشفة في النتيجة، وتقسيم الصفحات الطويلة دون تعديل المنطقة نفسها مرتين.
